# Regras para nome de variaveis 
Os nomes podem conter letras, dígitos e o caractere de sublinhado (_).
Os nomes devem começar com uma letra ou um sublinhado.
Os nomes devem começar com letra minúscula e não podem conter espaços em branco.
Os nomes diferenciam maiúsculas de minúsculas ("myVar" e "myvar" são variáveis ​​diferentes)
Palavras reservadas (como palavras-chave do C#, como ` int_` ou `_` double) não podem ser usadas como nomes.
